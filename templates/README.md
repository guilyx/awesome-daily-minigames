# Awesome Daily Minigames [![Awesome](https://awesome.re/badge-flat2.svg)](https://awesome.re)

> A curated list of games that give you one puzzle a day and then politely ask you to come back tomorrow.

Wordle proved something small: a puzzle everybody gets exactly one of, at the same time, with a spoiler-free way to brag about it. Hundreds of games have been built on that shape since — some brilliant, most forgettable. This list is the curated cut: **{{GAME_COUNT}} games across {{CATEGORY_COUNT}} categories**, including **{{REDDIT_COUNT}} that you play inside a Reddit post** without ever leaving the app.

Every entry is free to start playing, resets on a daily cadence, and is short enough to finish before your coffee goes cold.

## Contributing

Found something missing, or something that has gone dark? [Open an issue]({{REPO_URL}}/issues/new/choose) or send a pull request — it is a one-line change to a YAML file.

Read [CONTRIBUTING.md](CONTRIBUTING.md) first; it covers what gets in, what does not, and how to regenerate the README. This list is deliberately curated rather than exhaustive, so a game being real is not on its own an argument for adding it. If you want *every* daily game ever shipped, [aukspot/dles](https://github.com/aukspot/dles) has 700+ of them and is excellent.
